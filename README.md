# Mina Academy · 英文學習表整合版

免登入的 K-pop 練習生英文學習 PWA，適合 iPad Safari。

## 使用方式

1. 選「單字練習」「生活用語」或「句型練習」。
2. 選主題與練習卡。句型卡可切換「這一組的不同說法」，逐句聽、逐句跟唸。
3. 按「聽發音」、自行跟唸後按「我跟著唸了」，再玩「舞台小挑戰」。挑戰是讀英文選中文，作答時會隱藏中文提示。
4. 每天聽、跟唸、答對各三張不同卡，完成安可任務。不同說法共用該張卡的每日獎勵。

## 教材範圍

根據使用者提供的 12 頁英文學習表逐頁轉錄。包含 28 類單字、41 組生活用語與 37 組簡易句型；共 303 張卡、451 個單字或可播放說法。

按掃描表逐列建立 225 張單字卡，包括 am、are、is 等表內變化形。原表註記為 222 個詞，與逐列卡片數不同，因此介面使用分類內卡片數，不宣稱 222 個不同詞。沒有依原表手寫勾選預設孩子已學會。

教學整理：斜線選項拆成可單獨播放的完整句子；可省略的 please、now 等選用自然完整形式。第 35 組生活用語的簡略否定回答補成完整句；第 38 組的空白位置以 park、here 示範。be、a/an、many/much 等中文加上簡短用法提示；the 的中文改為特指說明。這些是便於練習的整理，不是逐字影印。

每張卡保留 PDF 頁次與原表組號。PDF 第 1 頁對應紙面第 2 頁，依此類推。原 PDF、個人姓名和手寫記號未放入部署檔案。

## 更新網站

將此資料夾的 7 個檔案直接上傳 GitHub 儲存庫根目錄：index.html、app.js、curriculum.js、sw.js、manifest.json、icon.svg、README.md。不要只上傳 ZIP，也不要漏掉 curriculum.js。

GitHub Pages 部署完成後，在原網址重新整理。舊頁面可能需關閉重開；不需要清除網站資料。教材會隨靜態資源一起離線快取。

## 進度與語音

保留 minaState 星光／勇氣與原 31 張卡位置，將舊的數字索引獎勵轉為固定教材 ID。新增 minaCourse 儲存目前卡片及曾答對的卡片。所有進度僅在同一網站來源、同一瀏覽器保存，沒有雲端同步。

跟唸是自行確認，不錄音、不判斷發音準確度。聽音任務只在瀏覽器回報播放結束後計入；發音及離線語音可用性取決於裝置。請在 iPad Safari 實際試聽。
